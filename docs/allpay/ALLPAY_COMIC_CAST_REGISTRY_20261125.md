## 2. 새로 추가하는 7화 승인 캐스트

사용자가 대화에서 제시한 **7화 1번·2번 컷 이미지**만 새 고정 캐릭터의 기준이다. 같은 에피소드 전체에서 두 이미지의 인물 외형을 이어받는다.

### ALLPAY-EP07-M01 — 남성 주인공 (7화 고정)

- 성인 한국인 남성, **성인 6~7등신에 가까운 자연스러운 비율**. 어린아이·치비 2.5~3등신으로 재해석 금지.
- 얼굴: 갸름한 턱선, 비교적 높은 콧대, 짙은 눈썹과 큰 감정 표현. 초기 컷의 20~30대처럼 보이는 동일한 성인 인물.
- 머리: **짙은 갈색 / 밤색의 자연스럽고 풍성한 웨이브**, 옆으로 갈라져 이마 일부를 덮는 실루엣과 밝은 갈색 하이라이트.
- 고정 의상: **남색/네이비 집업 작업형 재킷**, 흰색 또는 밝은 회색 이너. 회차 내 캐주얼 앞치마·교복·정장으로 임의 전환 금지.
- 연기: 호탕한 안도감 → 청구서 발견 → 황당함/절망 → 자료 확인 → 차분한 이해. 표정만 크게 바뀌고 얼굴 골격·머리와 의상은 유지.
- 인물 형태 오류 금지: **양팔 2개, 양손 2개, 손가락·팔 관절 자연스럽게**. 컷별로 손이 가려지는 것은 허용하지만 손/팔의 중복은 폐기 사유.

### ALLPAY-EP07-F01 — 여성 주인공 (7화 고정)

- 성인 한국인 여성, 자연스러운 성인 비율. 어린아이/치비 변경 금지.
- 얼굴: 부드러운 타원형 성인 얼굴, 자연스러운 코·눈·입, 밝고 현실적인 표정.
- 머리: **짙은 갈색 턱선 부근의 깔끔한 단발, 옆 가르마**, 컷 간 길이·색·앞머리 변형 금지.
- **얇은 원형 금속 안경** 필수. 안경을 없애거나 모양·색을 임의 변경하지 않는다.
- 고정 의상: **연녹색/세이지 그린 칼라 셔츠**, **어두운 차콜/보라 기운 가디건 또는 재킷**. 사용자가 올린 7화 1·2번 컷 외형이 우선.
- 연기: 고지서 제시, 현실을 알려주는 친근한 안내, 짧은 농담과 웃음. 냉정한 심사 담당자로 오인되게 연출하지 않는다.
- 인물 형태 오류 금지: 양팔 2개, 양손 2개, 추가 손/팔/손가락 없음.

1. **기존 캐릭터가 먼저:** 제작 전 이 등록부와 1·2화 GitHub 이미지 확인. 특정 에피소드가 사용한 고정 인물은 해당 승인 마스터를 반드시 사용.
2. **7화는 M01/F01만 사용:** 사용자가 별도로 신캐를 승인하지 않는 한 동일 역할에 다른 얼굴이나 다른 의상을 생성하지 않음. 8화 이후에 새 인물이 필요한 경우 기존 캐릭터를 재활용하거나 **신규 ID를 이 등록부에 추가한 뒤 승인**. 기존 ID 덮어쓰기 금지.
3. **한 화면에 한 컷:** 1장의 9:16 이미지에 1개의 스토리 장면만. 5~8장 합본·만화 그리드 생성 뒤 잘라 쓰기 금지.
4. **화풍:** 1~2화의 성인 인체 비율, 선명하지만 과하지 않은 애니/한국 웹툰 채색, 세밀한 머리 하이라이트·입체 배경·검정 말풍선 유지. 어린이용 SD 화풍/지나친 팝아트 얼굴 변경 금지.
5. **표지 요소:** AllPay 로고, `올페이 | 오늘도 결제합니다`, 회차 번호, **노란 폭발형 제목 말풍선**(작품 특성에 맞게).
6. **검수 게이트:** ① 얼굴·헤어·안경·의상 vs 참조컷 ② 인물 양팔/양손/손가락 ③ 이미지 한 컷 여부 ④ 1080×1920 및 왜곡 없음 ⑤ 말풍선/제목/숫자/전화번호 ⑥ 거래 유형 지원 여부·증빙·심사·송금 시점 문구. 하나라도 불합격하면 다음 컷으로 진행하지 않음.
